# Tericflow for macOS

Download the newest **Tericflow_x.y.z_universal.dmg** from
[Releases → Latest](https://github.com/tericsoft-product/tericflow-macos-releases/releases/latest)
(no GitHub account needed). It runs on Apple Silicon and Intel Macs.

1. Open the .dmg and drag Tericflow into Applications.
2. Open Tericflow from Applications. It sits in the menu bar and opens in your browser.

Installed copies update themselves: when a new version is out, Tericflow offers **Update & restart**.

This repository holds release files only. They are published automatically by the release workflow
of the (private) tericflow-v2 repository.
